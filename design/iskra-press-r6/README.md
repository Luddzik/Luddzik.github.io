## Reference and adaptation
Reviewed https://www.fromsoftware.jp/ww/, https://www.fromsoftware.jp/ww/pressrelease.html and https://www.fromsoftware.jp/ww/company_about.html on 2026-10-15 using web retrieval. FromSoftware separates company, products, press releases, recruitment and support; product entries expose concise genre, availability and player facts. Its company page uses factual rows. Live visual inspection was unavailable this session, so this is a structural adaptation, not a verified pixel reproduction.

Retain the Iskra slash entrance and approved vector logo. Main navigation: Games / Company / Press / Contact; logo returns home. Default portfolio shows only NeuroShift; existing 3/8 game specimen modes remain review-only.

## Typography
Barlow Condensed 500–700: headings, game titles and panel labels. Barlow 400–600: body, navigation and metadata. Fonts load from Google Fonts with system fallbacks. Existing vector wordmark is unchanged. Technical condensed titles suit NeuroShift; body copy stays readable. These choices apply to this proposal, superseding the older production font directions only here.

## Audience assessment
Players: game-first entry, genre description, gameplay and playable demo.
Press: accessible game facts and individual source-resolution downloads with in-development context.
Publishers: explicit publishing contact and playable evidence. Before launch, add owner-verified founder/team experience, relevant shipped-work credits and the specific partnership sought. Do not invent funding requirements, launch dates, commercial traction, team size or publisher relationships. A website supports a pitch; it does not substitute for a pitch deck and production plan.
