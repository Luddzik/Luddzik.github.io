# Iskra — proposal 04

Open index.html in a browser. This is a local design proposal; production is unchanged.

## Reference
https://www.fromsoftware.jp/ww/?lng=en — inspected live in headless Chrome on 2026-10-14; reference screenshot in previews/reference.png. Adapted principles: monochrome studio chrome, prominent game imagery, direct navigation, factual game information, restrained company presentation. No FromSoftware artwork or brand assets are used in the proposal.

## Identity
Custom vector uppercase lettering, with an ascending incision through the I. Compact initial and complete favicon sizes supplied in brand/. This is a design candidate, not a trademark clearance.

## Motion and scale
Homepage has a bounded featured area with selectable world/gameplay/assembly views; crossfades, foreground scroll depth, explicit video playback controls and a gameplay dialog. Reduced-motion preference removes transforms/transitions and prevents automatic gameplay playback. The catalog supports arbitrary entries; 1/3/8-item modes demonstrate its grid growth. Future entries are explicit design specimens. In production the preview selector is removed and the list is populated from game data; pagination should be added when needed.

Real NeuroShift art and gameplay reused from the preceding local proposals. No invented games, releases or company achievements. The upcoming-project block deliberately makes no announcement.

## Delivery
Responsive static HTML/CSS/JS, vector brand assets, ICO, Apple and app icons, browser screenshots and check results. Integration into Next.js follows direction selection.

## Multi-game entrance
portfolio.html demonstrates three expanding panels: one actual game and two explicitly labelled layout specimens. Pointer hover, keyboard focus and tapping the panel button change the active world. Up to three editorial selections keep the homepage bounded; the full catalog remains separate.
